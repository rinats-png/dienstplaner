# Handbuch: Kunde / Inhaber

Rolle `kunde`. Das ist die Rolle älterer Zugangscodes ohne Rollenangabe (ohne Angabe gilt `kunde`). Sie hat dieselben
Rechte und dieselbe Sicht wie die Leitung — siehe [Handbuch Leitung](leitung.md) ([Übersicht](README.md)).

Unterschiede in der Praxis:

- Beim Vergeben von Rollen behandelt die Oberfläche `kunde` wie `leitung`.
- Ein Zugang dieser Rolle ist oft an keine Person gebunden; persönliche Funktionen (Stempeln, eigener Kalender,
  Push) setzen eine Person voraus.

Empfehlung: Neue Zugänge mit ausdrücklicher Rolle ausgeben (`leitung`), ältere `kunde`-Codes bei Gelegenheit ersetzen.
